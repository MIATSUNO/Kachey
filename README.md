# Kachey — Music Vault

O Kachey é um projeto de música para navegador, publicado em [kachey.neocities.org](https://kachey.neocities.org/). O site reúne ferramentas para explorar referências musicais e acordes, organizar músicas e composições e apoiar a prática e a edição de áudio.

## Acessar

- [Abrir o Kachey](https://kachey.neocities.org/)

## Aplicativo Android

Este repositório também disponibiliza o APK `musicvault.apk`. O arquivo está publicado como build para teste; confira a origem e os requisitos no próprio aparelho antes de instalar. Não há neste repositório instruções de versão, assinatura ou compatibilidade verificadas.
